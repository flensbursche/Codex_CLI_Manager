# Security Policy

## Unterstützte Versionen

Sicherheitskorrekturen werden für die jeweils neueste veröffentlichte Version bereitgestellt.

## Sicherheitsproblem melden

Bitte verwende GitHubs Funktion **Report a vulnerability** im Bereich **Security Advisories** dieses Repositories. Veröffentliche keine Zugangsdaten, Session-Inhalte, lokalen Pfade oder Exploit-Details in einem öffentlichen Issue.

Gib nach Möglichkeit die betroffene Version, eine reproduzierbare Beschreibung und die erwartete Auswirkung an. Eine erste Rückmeldung erfolgt üblicherweise innerhalb von sieben Tagen.
